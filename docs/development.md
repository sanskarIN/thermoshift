# Development

## Domain-first changes

When changing conversion behavior, start in `thermoshift-core`, add or update regression tests, then expose only the minimal adapter changes through WASM/Tauri. Do not duplicate formulas in React.

## Frontend changes

Keep reusable metadata in `src/data`, infrastructure in `src/lib`, user state in hooks/components, and screen-level composition in `App.tsx`. All interactive elements must be keyboard reachable and have visible focus.

## Generated WebAssembly

`apps/web/src/generated/thermoshift_wasm` is generated by `wasm-pack` and intentionally ignored. Build it with:

```bash
npm --workspace @thermoshift/web run wasm:build
```

Generated artifacts should not be hand-edited.

## Conventional commits

Keep commits atomic and meaningful. Prefer one behavior/refactor/documentation concern per commit when separable. Run the smallest relevant test before committing and the full quality gate before a release.
